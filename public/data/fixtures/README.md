# Fixture Data

This directory contains **fixture data for development and testing**. These files are not the output of the actual simulation engine — they are synthetic JSON files that conform to the data contract defined in `src/contracts.ts`.

## Files

- `candidates.json` — 18 candidate market sites (3 benchmarks + 15 discovered squares), each with OSM-derived indicators
- `result-<candidate-id>-<scenario>.json` — simulation results for each passing candidate in both SUNNY_SAT and RAINY_SAT scenarios
- `brief.json` — a sample council brief recommending one candidate

## Generation

These fixtures are generated by the `src/ui/__fixtures__/gen.ts` script using a seeded RNG (mulberry32, seed=42) to ensure deterministic, realistic-looking data:

```bash
node --loader tsx/cjs src/ui/__fixtures__/gen.ts
```

This command writes all fixture files to this directory.

## Design Notes

- **Deterministic**: The same seed always produces the same trips, scores, and bottlenecks, so fixtures are reproducible across sessions and CI runs.
- **Realistic geometry**: Trip paths are anchored to actual footway polylines from `public/base/footways.json` (or parsed from OSM data).
- **Persona variation**: Scores vary by site, persona, and scenario. At least one site has a persona score below 40 to trigger the "fails a stakeholder group" guard.
- **No CHRISTMAS_MARKET results**: The fixture set intentionally omits CHRISTMAS_MARKET scenario files to test offline error handling.

## Contract Compliance

Fixtures are validated by `src/ui/__fixtures__/fixtures.test.ts`, which asserts:
- Correct JSON structure and types
- All trips have >= 100 entries
- Trip coordinates stay within [lng, lat, tSec] format
- Persona scores are in [0, 100]
- All referenced candidates exist
- SUNNY vs RAINY scenarios have different scores
